# 走查能力清单（步骤 1）

> 只列**代码里真实存在的入口与行为**。素材里出现清单外的能力 = 素材错误（不走查）。
> 盘点方式：读 `AppShell.Wiring.cs` 的订阅、`RuleSet.CreateDefault()`、`TaskbarChipLayer` / `MainPanelWindow` / `SceneEditorWindow` / `TrayService` 的事件，以及 `Core/` 各服务的公开方法。

## 一、入口（4 个）

| 入口 | 载体 | 通道 |
| --- | --- | --- |
| E-1 热键 | `Ctrl+Alt+Shift+D`（可改） | 规则树，三段式 |
| E-2 场景胶囊 | 贴任务栏的 topmost 小窗（最多 7 枚 + `+N` 溢出） | 左键走规则树；右键三个显式命令 |
| E-3 托盘菜单 | `NotifyIcon` 右键；左键单击切单窗口模式、双击开面板 | 显式命令，不进规则层 |
| E-4 主面板 / 详情侧窗 | WPF 深色窗口 | 显式命令 |

## 二、能力

| C-ID | 能力 | 入口 | 关键约束 |
| --- | --- | --- | --- |
| C-01 | 新建场景：把这块屏幕上未归入场景的可见窗口收起并落快照 | E-1 / E-3 / E-4 | 按屏 fail-closed；管理员窗口跳过并计数 |
| C-02 | 展开最近的场景（按屏独立轮转） | E-1 / E-3 / E-4 | 只作用于当前屏 |
| C-03 | 展开全部已收起场景（按屏） | E-3 / E-4 | 只作用于当前屏 |
| C-04 | 收起所有已展开场景（按屏） | E-1 规则 | 只作用于当前屏 |
| C-05 | 单个场景切换：运行中 → 收起 / 已收起 → 展开（组保留） | E-2 左键 / E-4 场景行 | 场景永不自删 |
| C-06 | 打开已关闭场景：已运行窗口摆回保存位置，缺失的程序启动后接管 | E-2 左键 / E-4「打开」 | 12 s 内轮询新窗口；同一场景连点去重 |
| C-07 | 关闭场景窗口：只对组内句柄发 `WM_CLOSE`，快照保留 | E-2 右键 / E-4「关闭窗口」 | 绝不按 exe 路径扫 |
| C-08 | 删除场景：窗口交回桌面 + 删快照 | E-2 右键 / 详情窗 | — |
| C-09 | 重命名场景（快照 + 运行时组同步） | E-2 右键 / 详情窗 | — |
| C-10 | 场景标识：8 色 + 可选数字 1–9 + 左上/右上，画进窗口图标 | 详情窗 | 纯几何绘制，无 emoji |
| C-11 | 调色板 8 色可改 / 恢复默认，同步已用该色的场景 | 详情窗 | 映射「同时生效」，不链式替换 |
| C-12 | 场景详情：列出场景内窗口，逐个移除 | E-4「详情」 | 至少保留 1 个窗口 |
| C-13 | 场景详情：列出这块屏幕全部窗口并追加，运行中立即接入 | E-4「详情」 | 属于其它场景 / 另一屏的拒绝 |
| C-14 | 单窗口模式：切到某窗口时，同场景窗口当一个整体，其它场景收回胶囊、其余窗口最小化 | E-3 左键 / E-4 开关 | 手动最小化的窗口不被弹回 |
| C-15 | 多显示器按屏隔离 | 全部 | 屏幕未知 = 什么都不做 |
| C-16 | 开机自启（HKCU Run 项） | E-3 / E-4 | 写入失败回滚 |
| C-17 | 改热键（录制）+ 冲突回退默认 + 提示 | E-4 | 至少含 Ctrl/Alt/Win 之一 |
| C-18 | 外观：程序图标 / 标识尺寸两个滑块，实时重画 | E-4 | 90% / 55% 默认，区间夹取 |
| C-19 | 主面板位置记忆、说明窗口 | E-4 | DIP 记忆，越界夹回 |
| C-20 | 胶囊贴任务栏 + 被压住自愈 + 溢出菜单 | E-2 | 1.7.1 起事件驱动 |
| C-21 | 崩溃 / 强杀恢复：`recovery.json` + 失效图标清理 | 启动 | 身份校验 PID + 启动时间 |
| C-22 | 以管理员身份重启（`--elevated-restart` 等旧实例释放互斥体） | E-3 | 取消 UAC = 保持原实例 |

## 三、硬限制（素材不得假设超出）

- Win11 无 DeskBand：胶囊是浮窗，无法真正嵌进任务栏
- 不接管窗口管理：删除场景即完全交还系统
- 不做缩略图 / 虚拟桌面 / 替换任务栏
- 只匹配普通桌面窗口：UWP、更高完整性级别的窗口可能收不进去
- 场景按 exe 路径重启；exe 已卸载的项会被跳过
